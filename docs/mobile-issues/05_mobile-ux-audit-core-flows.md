## Overview

Audit the current Vue app on phone-sized screens and improve the highest-friction flows before or alongside native packaging.

The v1 mobile app will only feel good if the underlying responsive experience is strong.

---

# Goals

1. Make the current UI comfortable on small screens
2. Reduce tap-target, spacing, and overflow problems
3. Prioritize the flows that matter most in a mobile app

---

# Core Flows To Audit

- Browse and filter cocktails
- My Bar / ingredient management
- Cocktail detail view
- Drink logging
- Authentication flows
- Onboarding / tutorial flows

---

# UX Focus Areas

- Tap target size
- Filter usability on narrow screens
- Modals and overlays on mobile
- Sticky actions / bottom-reachable controls
- Text wrapping and overflow
- Scroll behavior
- Safe-area behavior
- Keyboard behavior for forms and search

---

# Deliverables

- Mobile QA checklist for core flows
- Prioritized list of UI issues found
- Fixes for the highest-severity mobile UX problems

---

# Acceptance Criteria

- Core flows are reviewed on phone-sized layouts
- Highest-friction issues are documented
- Key UX blockers are fixed or split into follow-up issues
- Mobile app no longer depends on desktop-oriented interactions for primary flows
